# 扫描性能预算：用户目录全扫 <60s，普通权限，UI 不阻塞

扫描内核以"用户目录（含 AppData）首次全扫 <60 秒"为硬预算，运行于普通用户权限（不用 MFT、不请求管理员），扫描在独立线程执行、UI 全程可交互并显示进度。该预算决定架构：多线程并行遍历（jwalk 类）+ 扫描/规则/UI 三层解耦。

理由：若接受管理员+MFT 可以快 10 倍（WizTree 路线），但违背零权限、零误删的产品边界；60s 是"喝口水的等待"与"架构复杂度"的平衡点。

## Considered Options

- MFT 直读（WizTree 方式）：秒级，但需要管理员权限，且只能读 NTFS 元数据、拿不到规则的判定信息（如 package.json 存在性）
